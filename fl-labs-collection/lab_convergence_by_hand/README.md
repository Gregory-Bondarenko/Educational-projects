# Сходимость FedAvg вручную

Самостоятельная работа №2 по дисциплине «Федеративное машинное обучение»

## Задача

У трёх клиентов квадратичные функции потерь f_k(w) = (a_k/2)(w − m_k)² с разными минимумами и кривизной. Из точки w₀ = 2 с шагом 0.1 нужно посчитать глобальный градиент и разброс градиентов ζ², сделать один раунд FedAvg при E = 1 двумя способами, найти стационарную точку и объяснить, что изменится при E = 20

## Решение

Глобальный градиент равен взвешенной сумме градиентов клиентов, ζ² равен взвешенной сумме квадратов их отклонений от глобального. Раунд считается через глобальный градиент и через честное усреднение локальных моделей. Стационарная точка: w* = Σ(n_k/N)·a_k·m_k / Σ(n_k/N)·a_k

## Результат

```
client   n  a  m  share  grad  deviation  weighted_sq  w_local
     A 100  1  1    0.5   1.0        1.6        1.280      1.9
     B  60  1  3    0.3  -1.0       -0.4        0.048      2.1
     C  40  2  4    0.2  -4.0       -3.4        2.312      2.4
F'(w0) = -0.6000, zeta^2 = 3.6400
w1 через глобальный градиент = 2.0600, через усреднение моделей = 2.0600
w* = 3.00 / 1.20 = 2.5000
```

Оба способа дают 2.06: при одном локальном шаге усреднение моделей и есть шаг градиентного спуска по общей функции потерь. Стационарная точка 2.5 лежит между минимумами клиентов, и шаг идёт к ней. Она не совпадает с простым средним минимумов (2.2): у клиента C функция вдвое круче, и он тянет сильнее своей доли данных

При E = 20 каждый клиент успеет почти дойти до своего минимума, и сервер будет усреднять 1, 3 и 4, получая около 2.2 вместо 2.5. Сходимость в раундах ускорится, но в смещённую точку. Чем больше ζ, то есть чем сильнее различаются данные клиентов, тем больше это смещение
