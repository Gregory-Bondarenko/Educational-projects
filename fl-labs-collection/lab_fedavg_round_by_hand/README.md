# Один раунд FedAvg вручную

Практическая работа №2 по дисциплине «Федеративное машинное обучение»

## Задача

Модель из одного параметра, на сервере w₀ = 1.0. Три клиента сделали по 5 шагов локального SGD и вернули свои значения. Нужно посчитать, что получит сервер после агрегации FedAvg, и объяснить, почему один клиент влияет сильнее остальных

## Решение

Вес клиента равен его доле данных n_k/N, новая модель сервера равна взвешенной сумме моделей клиентов. Скрипт считает то же самое двумя способами: через модели и через обновления δ_k

## Результат

```
client   n  delta  w_k  share  contribution
     A 100    0.4  1.4    0.5          0.70
     B  60   -0.2  0.8    0.3          0.24
     C  40    0.6  1.6    0.2          0.32
сумма долей = 1.00
w1 через модели = 1.2600, через обновления = 1.2600
```

Сервер получает w₁ = 1.26. Оба способа совпадают, потому что веса в сумме дают единицу, а значит серверу достаточно получать одни обновления

Клиент A даёт 0.20 из итогового сдвига 0.26, хотя его δ по модулю меньше, чем у C: у него половина всех данных. Это делает FedAvg похожим на обучение на объединённой выборке, но и позволяет крупному клиенту перекрикивать мелких с другим распределением
