# СберАвтоподписка: кто оставит заявку

Финальная работа курса Skillbox по машинному обучению, январь 2024, первый курс. Самый ранний проект в репозитории. Репозиторий на платформе курса: [GitLab Skillbox](https://gitlab.skillbox.ru/grigorii_bondarenko/ml-project-skillbox)

По данным Google Analytics с сайта «СберАвтоподписки» нужно предсказать, совершит ли посетитель целевое действие: оставит заявку, закажет звонок, начнёт диалог. Предсказание делается по тому, что известно о визите заранее: источник трафика (utm-метки), устройство, браузер, разрешение экрана и город

## Результат

CatBoost с балансировкой классов, **ROC-AUC 0.77** на тестовой выборке (0.84 на обучающей). Целевых действий в данных около 6.5%, так что без балансировки модель просто отвечала бы «нет» на всё

Сильнее всего на прогноз влияют город, разрешение экрана и рекламная кампания

Консольное приложение спрашивает параметры визита и выдаёт вероятность заявки:

```
$ python src/main.py
Введите данные пользователя

utm_source: bByPQxmDaMXgpHeypKSM
utm_medium: referral
utm_campaign: LTuZkdKfxRGVceoWkVyg
utm_adcontent: JNHcPlZPxEMWDnRiyoBf
device_category: mobile
device_brand: Samsung
device_screen_resolution: 288x1000
device_browser: Android Webview
geo_country: Russia
geo_city: Saint Petersburg

Прогноз: пользователь совершит целевое действие (вероятность 0.73)
```

## Как делалось

`01_preprocessing.ipynb` склеивает сессии с хитами по `session_id`, размечает целевые события, переводит разрешение экрана в площадь и кодирует категориальные признаки числами. Словари кодировок сохраняются в `encoders/`, чтобы консольное приложение переводило введённые строки теми же кодами

`02_training.ipynb` обучает CatBoost и сохраняет модель в `model/model.pickle`

## Ограничения

Разметка сделана на уровне хитов, а не сессий: одни и те же признаки визита встречаются в данных и с меткой 1, и с меткой 0 (так у 7% комбинаций признаков). Аккуратнее было бы свернуть хиты в сессии и ставить 1, если в сессии было хотя бы одно целевое действие, но для этого нужны исходные выгрузки на 4.5 ГБ

## Запуск

```bash
pip install -r requirements.txt
python src/main.py
```

Исходные `ga_sessions.csv` и `ga_hits.csv` в репозиторий не входят из-за размера. Если положить их в `data/`, первый ноутбук пересоберёт `data/data.csv`
