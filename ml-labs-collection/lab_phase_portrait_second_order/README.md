# Фазовый портрет системы второго порядка

Обязательное задание №4, вариант b по дисциплине «Машинное обучение»

![Результат](result.png)

## Задача

Построить фазовый портрет колебательной системы x'' + 2ζωx' + ω²x = 0 на плоскости (x, x') с траекториями, полем направлений и изоклинами

## Решение

Траектории из 72 начальных точек интегрируются через `odeint`. Изоклины для наклона k выводятся аналитически: x' = −ω²x/(k + 2ζω)

## Результат

При ζ = 0.3 начало координат является устойчивым фокусом, траектории закручиваются к нему по спирали
