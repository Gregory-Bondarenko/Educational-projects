## Тематические семьи

Несколько работ решают близкие задачи разными методами — это не повторы, а сознательное сравнение подходов:

- **Расстояние между кластерами** — три разных метрики: Вассерштейна (между двумя кластерами целиком), Махаланобиса (от точки до кластера) и геодезическое (по поверхности плотности, а не по прямой). Разные постановки, разная математика.
- **Клеточные автоматы** — три разных правила перехода: классическая «Жизнь», версия с законом сохранения массы, двухслойная версия «хищник — жертва».
- **Фазовые портреты** — сначала одна колебательная система 2-го порядка (2D), потом обобщение на два связанных осциллятора (4D) с аппроксимацией траекторий по данным.
- **Аппроксимация прямой** — рекуррентный МНК (онлайн-обновление) и минимизация по норме Минковского (устойчивость к выбросам) — две разные проблемы одной темы.
