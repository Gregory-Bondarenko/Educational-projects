# Расстояние Махаланобиса от точки до кластеров

Обязательное задание №2, вариант b по дисциплине «Машинное обучение»

## Задача

Два кластера заданы средним и ковариационной матрицей, точка Q тоже задана. Найти расстояния от Q до каждого кластера и определить, к какому она ближе. Матрицы в условии несимметричные

## Решение

Ковариационная матрица обязана быть симметричной, поэтому берётся её симметричная часть (M + Mᵀ)/2. Дальше проверяются собственные значения: если матрица вырождена, распределение лежит на прямой, и для точки вне этой прямой расстояние бесконечно. Регуляризация C + εI здесь не спасает: расстояние получится огромным, но конечным, и будет зависеть только от выбранного ε

## Результат

После симметризации матрица кластера A становится [[3, 3], [3, 3]] с нулевым определителем: кластер вырождается в прямую y − 10 = x − 1, а Q на неё не попадает. Расстояние до A бесконечно, до B равно 2.86. Точка ближе к B

```
Расстояния Махаланобиса:
d_M(Q, A) = inf
d_M(Q, B) = 2.8590
```
