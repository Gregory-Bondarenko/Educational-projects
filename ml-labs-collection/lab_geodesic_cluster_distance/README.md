# Геодезическое расстояние между кластерами

Обязательное задание №1, вариант b по дисциплине «Машинное обучение»

![Результат](result.png)

## Задача

Два кластера заданы двумерными нормальными распределениями. Расстоянием между ними считается длина геодезической, то есть кратчайшего пути между центроидами по поверхности плотности их смеси

## Решение

Поверхность z = λ·p(x, y), где p это плотность смеси. Сама плотность имеет порядок 0.1, и без множителя λ поверхность почти плоская, поэтому высота пика задаётся параметром. Путь строится как прямая между центроидами с синусоидальными отклонениями по нормали к ней, коэффициенты подбираются минимизацией длины. Точность контролируется сгущением сетки и добавлением базисных функций, пока длина не перестанет меняться

## Результат

Евклидово расстояние 7.07, геодезическое 9.08. Путь почти совпадает с прямой: оба конца лежат на вершинах, и любой путь должен спуститься в седловину и подняться обратно, а обход в сторону только удлиняет горизонтальную часть
