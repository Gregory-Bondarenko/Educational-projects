# Двухслойный автомат «растительность и травоядные»

Творческое задание №3 по дисциплине «Машинное обучение»

![Результат](result.png)

## Задача

Построить двухслойный клеточный автомат, в котором правила каждого слоя зависят от другого слоя

## Решение

Первый слой это растительность с правилами, похожими на «Жизнь»: выживает при 2-5 соседях, если на клетке нет травоядного, рождается при трёх соседях. Изредка растение прорастает само, как от занесённых ветром семян. Второй слой это травоядные: выживают, только если рядом есть еда и соседей не слишком много, рождаются на клетках с растением

## Результат

За 300 ходов обе популяции сосуществуют: растений от 3 800 до 4 800, травоядных от 350 до 700, и численности колеблются вокруг этих уровней

## Запуск

```bash
python predator_prey_automaton.py
```
