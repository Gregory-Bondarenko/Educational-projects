# Educational-projects

Учебные проекты и лабораторные и курсовые работы за время моего обучения. Каждая папка — отдельный предмет или отдельный проект, самодостаточна: код/скрипты + отчёты + свой README с подробностями

## Содержание

### [vk-engagement-prediction](./vk-engagement-prediction)
Курсовой проект: прогнозирование вовлечённости (просмотров и лайков) постов в спортивном сообществе ВКонтакте. Сбор данных через VK API → очистка → обучение `RandomForestRegressor` → консольное приложение для прогноза. Плюс отдельная папка с экспериментами (кластеризация, попытка классификации, BI-выгрузка), которые не вошли в финальный пайплайн

### [ml-labs-collection](./ml-labs-collection)
14 контрольных/практических работ по дисциплине «Машинное обучение» — обязательные и творческие задания за несколько семестров. Темы: рекуррентный МНК, расстояния между кластерами (Вассерштейна / Махаланобиса / геодезическое), клеточные автоматы (игра «Жизнь», версия с законом сохранения, хищник-жертва), фазовые портреты динамических систем, оптимизация цены при случайном спросе и другое

### [r-labs-collection](./r-labs-collection)
Три лабораторные по дисциплине «Программирование на языке R»: анализ опроса методом идеальной точки, оценка риска штрафов за выбросы против затрат на очистные сооружения, регрессия индекса счастья по социально-экономическим показателям

### [de-labs-collection](./de-labs-collection)
Практические задания по дисциплине «Инженерия данных» — импорт/экспорт форматов, очистка и обогащение данных, скользящее окно и лаги для временных рядов, группировка и агрегация, объединение таблиц и поиск дублей. Формально задания рассчитаны на Deductor Studio, выполнены на Python

### [shop-sql-practice](./shop-sql-practice)
SQL-практика на примере схемы интернет-магазина

### [Database-Course-Work](./Database-Course-Work)
Курсовая работа по дисциплине «Проектирование Баз данных»

### [ML-Project-Skillbox](./ML-Project-Skillbox)
Учебный проект по ML в рамках курса от Skillbox. Оригинальный репозиторий: [gitlab.skillbox.ru/grigorii_bondarenko/ml-project-skillbox](https://gitlab.skillbox.ru/grigorii_bondarenko/ml-project-skillbox)
