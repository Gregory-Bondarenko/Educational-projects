## Как устроен репозиторий

Каждая папка самодостаточна: свой README, код, данные (или скрипт, который их генерирует) и картинки с результатами. Если исходные данные были привязаны к варианту задания и в репозиторий не попали, рядом лежит генератор синтетических данных той же структуры, чтобы код запускался от начала до конца

Отчёты и презентации в Word и PowerPoint лежат рядом с кодом: в папке `reports/` у проектов и файлом `report.docx` у отдельных лабораторных. GitHub такие файлы в браузере не открывает, поэтому постановка, ход решения и выводы продублированы в README
